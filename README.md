# RapidFuzz 알고리즘을 이용한 도서검색 서비스 프로토타입


## 1. 프로토타입 설명

* 프로토타입의 기능: 사용자가 제목, 저자, 출판사를 검색 창에 입력하고 각종 필터들을 선택하여 원하는 책을 검색하는 프로그램.

* 프로토타입 사용 대상자: 한국어 외 다른 언어(영어, 독일어, 프랑스어, 스페인어 등)으로 작성된 책을 검색하려는 사용자

* 프로토타입을 사용하는 상황: 방대한 양의 외국어 원서들을 빠르게 검색해야 하는데 사이트에 접속하기 쉽지 않은 상황(ex. 서버 장애, 인터넷 사용 불가 등)

* 이 프로토타입이 필요한 이유: 한국인들은 도서를 검색할 때 한국의 도서관 사이트들을 많이 이용하는데, 이러한 도서관 사이트에 저장된 외국어 자료의 양이 전체 외국어 도서 수에 비해 부실하다. 따라서 외국어 도서를 검색하려면 외국 사이트들을 이용해야 하는데, 여러 가지 여건으로 인해 쉽지 않을 수 있다. 따라서 도서 데이터들을 한번에 다운받은 뒤 필요할 때마다 원하는 데이터를 필터링해서 검색할 수 있는 애플리케이션이 유용할 것이다.


## 2. 입력 데이터: 도서에 관련된 정보가 저장된 CSV 파일 형식 릴레이션.

* 데이터 종류(필드): `bookID`, `title`, `authors`, `average_rating`, `isbn`,`isbn13`, `language_code`, `num_pages`, `ratings_count`, `text_reviews_count`, `publication_date`, `publisher`
					  
* 데이터 출처: <https://www.kaggle.com/datasets/jealousleopard/goodreadsbooks>


## 3. 사용한 자료구조

* List

  * 검색 결과를 저장하고 표시하기 위한 자료구조. 검색 결과를 저장하는 results 변수에 사용된다.

* CSV

  * `load_books`의 `open`에서 CSV 파일을 읽는다. 쉼표로 자료를 구분하는 텍스트 파일로 엑셀 등 프로그램으로 실행하면 데이터를 쉽게 알아볼 수 있고, 단순 텍스트 에디터(Notepad, Vi, Nano 등)으로 편집할 수 있어 개발 환경이나 운영체제의 영향을 받지 않는다. 이 프로토타입에는 릴레이션 형식의 데이터를 표현한 파일이 필요한데, CSV는 이에 가장 적합하다.

* Dict

  * `load_books`의 `DictReader` 부분에 사용되었다. 각 도서에 관한 정보를 딕셔너리 형식으로 저장함. 파이썬에는 CSV 파일을 읽고 이를 딕셔너리 형식으로 저장하는 기능이 있는데, `Key`값을 필드 이름으로 하고 이에 해당하는 `Value` 값에 도서 정보를 저장하면 같은 필드끼리 일괄적으로 관리할 수 있다.


## 4. 사용한 알고리즘

* RapidFuzz(핵심)

  * 자연어 처리 알고리즘. 검색 단어를 기반으로 `title_score`, `author_score`, `pub_score`을 산출하는 과정에서 사용된다. 레벤슈타인 거리를 이용하여 입력한 단어와 검색 대상 단어의 유사도를 측정한다. Edit Distance Algorithm이라고도 한다. 유사도는 문자열 A를 문자열 B로 변경하기 위해 필요한 작업(추가, 변경, 삭제)의 수를 기준으로 평가한다. 작업 횟수가 적을수록 유사도가 높다고 판정된다. 검색 시 오타가 발생할 수 있는데, 적은 개수의 오타가 발생하더라도 사용자가 의도한 결과를 출력할 수 있다. (ex. "hary potar"라고 검색해도 "Harry Potter"에 관한 결과들이 출력됨)

* 안정된(다중 키 정렬 알고리즘(Tim Sort))

  * 선택된 필터별로 검색 결과를 정렬하는 곳(FILTERS 각주 부분부터)에 사용된다. 정렬 필터가 여러 개인 경우 정렬을 여러 번 진행해야 하는데 이때 어떤 키 값이 같은 데이터끼리는 다른 키 값으로 정렬해야 한다. 이때 불안정 정렬 알고리즘을 사용하면 이미 정렬된 키 값 묶음이 흐트러질 수 있으므로 반드시 정렬 알고리즘을 사용하여야 한다. 이 프로토타입에서는 Tim Sort를 사용하였다. Tim Sort는 평균 시간 복잡도가 O(n log n)이고, 거의 정렬된 데이터에 대해 시간 복잡도가 O(n)으로 다른 안정 정렬 알고리즘보다 시간 복잡도가 낮다는 장점이 있다.

* + 역순 정렬: 오름차순/내림차순 정렬을 라디오박스 형태로 나타내어 사용자가 선택할 수 있다.

* 선형 탐색 알고리즘: 조건에 부합하는 도서들을 탐색할 때 선형 탐색 알고리즘을 이용한다. `for row in books_data` 부분에서 사용된다. 


## 5. 설계/구현 방법

* 자연어를 이용하여 키워드를 입력하고 여러 개의 키들을 우선순위에 따라 정렬하여 결과를 출력한다. 필터의 활성화 여부를 선택하는 버튼에는 Tkinter의 BooleanVar가, 정렬 방향과 언어 선택에는 StringVar가, 시작과 끝 범위 설정에는 엔트리 위젯이 사용되었다. 이때 각 도서 정보 레코드들은 딕셔너리 형식으로 저장되고 각 Key의 Value별로 정렬된다. 정렬에는 파이썬 기본 정렬 알고리즘인 Tim Sort를 사용하였으며, 결과 출력은 Tkinter의 Treeview Table을 이용하였다.

* 아키텍처

  * 표현 계층: 입출력과 UI를 담당하는 계층이다.

  * 컨트롤러 계층: 로직, 데이터 처리와 표현 계층 사이의 상호작용을 담당하는 계층이다.

  * 로직, 프로세스 계층: Fuzzy 자연어 검색, 범위 필터링, 언어 필터링, 다중 키 정렬 등을 담당하는 계층이다.

  * 데이터 계층: CSV 파일을 프로그램에 적재하는 계층이다.
